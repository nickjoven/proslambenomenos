Rung 1 — the untended phase

Rung 3 — the winding number

backed statement · EQ3–EQ5 · clauses (c), (d) E(Δ) = K(1−cos Δ) + K(N−1)(1−cos((2π−Δ)/(N−1))), Δ* = π(N−3)/(N−2) ΔE(N) = E(Δ*) − NK(1−cos(2π/N)) ↑ 2K, rate = N·(λᵤ/2π)·√(det′H_min/|det′H_saddle|)·e^(−ΔE/D) The saddle is analytic: clamp one bond, the rest relax uniform. The barrier grows with N only because the twisted state's own strain relaxes — it saturates at 2K. Classical 1D topology buys no extensive protection; a chat-level guess to the contrary died at EQ5, pre-registration.
