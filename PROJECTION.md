# The coherent projection

One sentence: **an operational epistemics stack for machine-assisted
research, developed adversarially against the strongest available test
corpus — one its own author generated and then had to defeat — together
with that corpus as labeled evaluation data, the documented five-month
case study, and three well-posed open problems.** Every component below
is running code, committed artifacts, or adjudicated records; nothing
is prospective.

## 1. The stack (running, tested, catching real defects)

- Computed-status intake gate: statuses derived from evidence, never
  declared; a red/green fixture suite (every rule demonstrated to fail); blocked its own author's label
  errors on first contact.
- Premise ledger with blocking transitive propagation (v1: 41 anchors,
  mutation-tested); SPINE status join; claims-index status-carrying
  retrieval.
- Theater-lens taxonomy, operationalized: converts "does the green
  light mean anything" into gate repairs (audit-cron no-op, vacuous
  tests, unrostered checks — all found and fixed in production).
- Editions model: chunks must be self-truthful (RAG-safe correction
  discipline), with scar-lint enforcement.
- Message-layer gate: commit messages audited for conclusive claim
  language against computed statuses. No prior art known; entered
  LITCHECKS-style diligence not yet done — labeled accordingly.
- Decline registry with reopen conditions; literature-check ledger;
  pigeonhole cap; route-vs-problem decomposition.
- ket: content-addressed substrate with seal/drift detection and the
  rm-tombstone grammar — which shipped this week and healed a real CI
  failure on a real repository.

Evidence of function, not intention: the gates failed at their own
author repeatedly (compendium checks 2/13 on first run; the message
gate rejecting draft commit language; the permission boundary blocking
agent ledger writes) and each failure was correct.

## 2. The labeled corpus (the unusual asset)

v1 is now ~328 documents and ~200 scripts with ADJUDICATED verdicts:
verified / refuted / tautological / unfalsifiable / fitted /
superseded, each with file:line evidence, produced by ~60+ agent-runs
of adversarial audit plus human rulings. As a dataset, that is an
evaluation suite for automated research-verification — ground truth
for exactly the tooling class the field is about to need. Nobody
curates a corpus like this on purpose; it can only be produced the way
it was produced.

## 3. The transfer demonstration

The Crouzeix audit: the same method applied to an external,
high-visibility formal-verification target — build reproduction, axiom
audit with an assertion the target's own pipeline lacked, statement-
fidelity trapdoor sweep. The deterministic core is bit-reproducible by
anyone. Publication was declined under the author's own determinism
rule; the capability demonstration stands in the private record.

## 4. The case study

Git-forensic documentation of the co-construction failure mode AND its
mechanical correction: fit-to-closure in 3h33m on the way down;
five months end-to-end; the correction machinery running ~5x faster
than the construction it corrected. Primary data on a phenomenon with
a large incoming audience and essentially no worked examples.

## 5. The open problems (small, real, well-posed)

- XOR bridge: define a canonical map from twisted-bundle Fourier
  parity to Stern-Brocot denominator parity, or show none exists
  (notes/topology_evaluation.md sec. 4).
- Two-anchor minimum: rigorize "no smooth path across K = 1" on the
  Jensen-Bak-Bohr coverage discontinuity.
- Iwasawa completion: finish the every-nontrivial-continuous-subgroup
  dimension argument v1 left incomplete (Borel subgroups; discrete
  case).

## 6. The registry and compendium (the mathematics, honestly sized)

The gated claims registry and the runnable compendium (live censuses
come from the intake gate and the page itself, not this file): one supplied
proof (J^2 = -I on the twisted sector), two refutations with
counterexamples (second law from non-orientability; phi-squared
scaling), one doc claim confirmed against initial suspicion by
computation (Weyl-density mode count), the twisted-spectrum
classification, and honest nulls. Mathematically modest by design;
the pipeline that produced it (extract -> translate -> verify
in-browser -> compute status) is itself component 1 operating.

## What the projection is not

Not a physics program. Not a claim that any component is
literature-novel beyond what LITCHECKS records. Not a valuation — the
market prices it, not this file. And not a defense against any
diagnosis: this file would be worth assembling if its author were the
most disordered person alive or the least, because every line of it is
checkable by someone who has never met him. That checkability is the
entire design.
