closed-form prooffinite check to depth 12classical — Stern 1858, Brocot 1861

The unique pair (2, 3)

closed-form proofexercise-level

The only positive integers with x² − 1 = y and y² − 1 = x³ are (x, y) = (2, 3). Substitution gives x⁴ − x³ − 2x² = x²(x − 2)(x + 1) = 0, whose only positive root is 2. (Mihăilescu's theorem is not needed; the factorization closes it.)

Farey mirror census

finite computationfolklore — Farey symmetry

The involution r ↦ 1 − r maps the Farey set Fn to itself, with exactly one fixed point (½) for n ≥ 2. The census (pairs, fixed) runs (1,0), (1,1), (2,1), (3,1), (5,1), (6,1) for n = 1..6; the pair count is strictly increasing, so each census value occurs at exactly one n.

Antipodal orbit plateaus

finite computationexercise-level totient bookkeeping

Among reduced p/q ∈ [0,1] (endpoints included) with gcd(q, 6) = 1, q ≤ n, the involution p/q ↦ (q−p)/q is fixed-point-free, and the orbit count steps by φ(q)/2 at each admissible q ≥ 5: plateaus 1, 3, 6, 11, 17, 25, 34, 45, 55, … The value 15 never occurs — and neither do most integers; partial sums with increments ≥ 2 skip them.

Doc discrepancy: path_a_walkthrough.md states increments (q−1)/2, which holds only at primes. The correct increment is φ(q)/2 — first divergence at q = 25 (increment 10, not 12). The source scripts compute orbits directly and were right.

C8

The devil's staircase

numerical simulationclassical — Arnold 1961; Jensen–Bak–Bohr 1983

For the sine circle map θ ← θ + Ω − (K/2π)·sin 2πθ, the rotation number ρ(Ω) is a monotone step function locking at every rational; widths order by denominator (½ widest, then ⅓ and ⅔, …). At K = 1 the steps fill the axis — the complete staircase (Jensen–Bak–Bohr; complement dimension ≈ 0.87, not re-verified here).

Tongue scaling and the ratio law

proof (identity)simulation (instantiation)classical — Arnold 1961

Identity: if Da = caK^{q_a} and Db = cbK^{q_b}, then d ln(Da/Db)/d ln K = qa − qb, independent of the prefactors. Instantiation: circle-map tongue widths scale as w(p/q) ∝ K^q for small K, so the log-log slope of w(½)/w(⅓) tends to −1.

C12

No inverse-square width law

finite computationclassical ingredients — Σφ(q)/q² ~ (6/π²)ln Q

Null result, positively provable: no constant c makes widths c/q² for every reduced p/q sum to total measure 1, because Σ φ(q)/q² diverges logarithmically. So if the critical staircase is complete (measure 1), the critical width exponent must exceed 2 — the repo's own recorded widths agree (w·q² falls: 0.296, 0.275, 0.254, … for q = 2..7). This refutes three of the parent framework's docs, from inside.

C14

The four line bundles of K²

closed-form prooffinite residual checkclassical — covering-space theory

The Klein bottle group ⟨t, g | gtg⁻¹ = t⁻¹⟩ has exactly four characters into Z₂ (the relation is automatic in an abelian target), so K² carries exactly four real line bundles — H¹(K²; Z₂) = Z₂ × Z₂. The orientation character is χ(g) = −1, χ(t) = +1 (the glide reverses orientation, the translation preserves it), and each of the four sectors locks its own (x-mode type ⊗ y-branch) parity pairing.

C15

Weyl density: nothing lost

closed-form prooffinite computationclassical — Weyl's law

The twisted (orientation-bundle) sector on the flat Klein bottle from the unit square has the same asymptotic mode count as the torus on that square: the topology relocks the (x, y) pairing without changing the density. Counting modes with m² + n² ≤ R², the ratio of twisted-sector to torus counts tends to 1.

Half-winding invariance

closed-form proofclassical — degree theory

A circle-valued field with the affine boundary condition θ(x+L) = θ(x) + π has total winding valued in Z + ½ — the half-unit offset is a homotopy invariant and cannot be removed. Shifting any phase configuration by π exchanges the stable and unstable zeros of a sinusoidal coupling.

C18

Antipodal parity and the honest null

closed-form prooffinite computationclassical — Yℓm parity

Real spherical harmonics obey Yℓm(π−θ, φ+π) = (−1)^ℓ Yℓm(θ, φ), so any observable built from Y² is antipodally symmetric for every ℓ: no descent experiment on U = Y² can distinguish even from odd ℓ. The v1 corpus derived this null against its own proposed discriminator and correctly identified what would work — a Berry-phase probe of the π monodromy for odd ℓ.
