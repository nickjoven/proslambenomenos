# Declined derivations (append-only)

An explicit "we do not attempt this" ledger. Each entry withdraws a
derivability claim and records what the underlying fact becomes instead
(usually `imported`). Declining is a terminal disposition with a stated
reopen condition — not a parking lot. The decomposition rule: "X is
derivable from the framework" is a claim (refuted or asserted); "X
holds" is a separate claim (imported, with citation). Never conflate
them again — the conflation was v1's core failure mode.

## D-1 — Spatial dimension d = 3 (refused as forced; 2026-08-19)

The v1 route (SL(2,Z) "completes to" SL(2,R), dim = 3) names no
mathematical operation, and the audit showed the same premises admit
d = 1 and d = 2 — which refutes "forced," not merely leaves it open.
d = 3 is an imported observation. Reopen: an actual construction
forcing a 3-dimensional completion, entering as a claim with proof
evidence.

## D-2 — Standard Model hypercharges (declined; 2026-08-19)

v1's D41 claimed the assignment derivable from small-integer structure;
its own verification script hardcodes Q_nu = 0, Q_e = -1, N_c = 3 and
takes Gell-Mann-Nishijima as an input. Withdrawn. The assignment is
imported SM structure; anomaly cancellation is a consistency check on
the import, not a derivation. Reopen: a derivation whose verification
script contains no hardcoded charge.

## D-3 — The 2*pi in a0 = cH/(2*pi) (declined; 2026-08-19)

v1's derivation of the 2*pi breaks at an unexplained step
(a0_threshold.md:142-155) and defers to an external repository. The

conjecture that the literature already discusses; the contribution

Reopen: a derivation of the constant that closes without deferral.
